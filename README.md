# 🪷 Raksha Bandhan Digital Keepsake — For Muskan ❤️

A premium interactive Raksha Bandhan celebration web experience created with love by **Divyam** for his sister **Muskan**.

## ✨ Features
- 🪔 **Sacred Rituals**: Authentic Aarti, Diya lighting & Tilak blessings
- 🧵 **Handcrafted Rakhi**: 6 handcrafted Rakhi designs & interactive wrist tying ceremony
- 🍬 **Celebratory Mithai**: Traditional sweets offering (*Motichoor Laddoo, Kaju Katli, Gulab Jamun, Milk Cake*)
- 📸 **29 Precious Memories Gallery**: Dynamic photo showcase with click-to-scroll big size high-res preview and thumbnail filmstrip
- 📜 **Heartfelt Scroll Letter**: Royal handwritten scroll message from Divyam to Muskan
- 🎵 **Continuous Looping Music**: *"Tenu Sang Rakhna"* autoplaying seamlessly across the entire ceremony
- 📱 **Mobile & Desktop Optimized**: Fully responsive with golden marigold petals and festival ambiance

## 🚀 Deploying to Vercel
1. Import this repository into **[Vercel](https://vercel.com)**.
2. Framework Preset: **Vite**
3. Build Command: `npm run build`
4. Output Directory: `dist`
5. Click **Deploy**!

## 💻 Local Development
```bash
npm install
npm run dev
```
